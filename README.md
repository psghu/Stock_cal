# 股票买入股数计算器

一个零构建的静态网页，用于根据资产总和、当前股价和目标买入仓位，快速计算可以买入多少股。

## 功能

- 输入资产总和、股价、目标买入仓位百分比。
- 按 `1 股整数` 向下取整计算可以买入的股数。
- 显示预计花费、剩余现金、实际仓位、目标预算未使用金额。
- 提供 `5%`、`10%`、`20%`、`30%` 仓位快捷按钮。
- 使用浏览器 `localStorage` 记住资产总和和上次选择的仓位。
- 提供“清除记录”按钮，只清除本地保存的资产总值和仓位选择。

## 计算公式

```text
目标买入金额 = 资产总和 * 仓位百分比 / 100
可买股数 = floor(目标买入金额 / 股价)
预计花费 = 可买股数 * 股价
```
